# Ihaze Rwanda - One-Page Pitch

**NISR Big Data Hackathon 2026 | Agriculture Track**

---

## 🎯 THE PROBLEM (30 seconds)

**1,834 farming households in Rwanda** report worsening soil erosion AND face barriers preventing soil protection. Of these:
- **72% receive NO agricultural extension services**
- **60.59%** cite lack of finance as barrier
- **33.37%** cite lack of knowledge
- Geographic distribution shows Gakenke, Bugesera, and Rulindo most affected

**Current Challenge:** Extension officers lack a systematic way to identify and prioritize these vulnerable households for targeted support.

---

## 💡 THE SOLUTION (45 seconds)

**Ihaze Rwanda** transforms NISR agricultural survey data into an actionable decision-support platform:

### Core Features:
1. **District Prioritization Dashboard** - Compare all 30 districts on erosion + barriers + service gaps
2. **Barrier-Specific Filtering** - Separate households by finance, knowledge, labour, or tenure barriers
3. **Outreach Capacity Planner** - Model "what if we have 50 extension officers?" scenarios
4. **AI-Powered Explanations** - Optional OpenAI integration explains statistical patterns in plain language
5. **Transparent Methodology** - All calculations documented, sources cited, limitations disclosed

### Technical Stack:
- **Frontend:** Next.js 15 + React + Tailwind CSS
- **Backend:** Python (FastAPI option available)
- **Data:** 16,057 households from NISR Agricultural Household Survey 2016-2017
- **AI:** OpenAI API (opt-in, with explicit disclosure)

---

## 📊 THE EVIDENCE (30 seconds)

Our analysis of **16 NISR SPSS data files** revealed:

| Finding | Impact |
|---------|--------|
| 26.84% of households receive ANY extension service | **73.16% service gap** |
| 61.26% practice erosion control | But **20.67% report INCREASING erosion** |
| Only 4.65% requested loans | Yet **60.59% cite finance as barrier** |
| Tomato losses: 36.68% of records show losses | **Post-harvest intervention opportunity** |

**Key Insight:** The overlap of need + barrier + no service = **precise targeting opportunity**
