# Ihaze Rwanda - Quick Demo Script (2-3 Minutes)

## Setup (Before Recording)

1. Start backend: `python -m backend.server` (in project root)
2. Start frontend: `npm run dev` (in frontend folder)
3. Open http://127.0.0.1:3000 in browser

## Demo Script

### Introduction (15 seconds)
"This is Ihaze Rwanda - an AI-powered agricultural insights platform for Rwanda. Ihaze means 'enough' in Kinyarwanda, reflecting our mission of food security through data-driven decisions."

### Main Dashboard (30 seconds)
1. Show the homepage with the hero section
2. Point out key features:
   - AI-powered insights
   - 30 districts coverage
   - Real NISR data from 2017 agricultural survey

### District Analysis (45 seconds)
1. Click "Explore Dashboard"
2. Show the district selector
3. Select a district (e.g., Kigali)
4. Show the data visualizations:
   - Erosion control statistics
   - Agricultural practices
   - Extension service coverage

### AI Query System (60 seconds)
1. Scroll to the AI Query section
2. Ask: "Which districts have the highest erosion problems?"
3. Show the AI analyzing and providing insights
4. Ask: "What are the recommendations for Gakenke district?"
5. Show how AI provides actionable recommendations

### Technical Highlights (20 seconds)
1. Mention the tech stack:
   - Next.js 16 frontend
   - Python FastAPI backend
   - Groq AI (Llama 3.1 70B)
   - Real NISR agricultural data

### Conclusion (10 seconds)
"Ihaze Rwanda helps policymakers and farmers make data-driven decisions for better food security. The code is open source on GitHub. Thank you!"

## Key Points to Emphasize

✅ Uses REAL government data (NISR 2017)
✅ AI-powered insights, not just static data
✅ Covers ALL 30 districts of Rwanda
✅ Practical recommendations for farmers and policymakers
✅ Modern, responsive design
✅ Open source and extensible

## Sample Questions to Demo

1. "Tell me about erosion control in Gakenke district"
2. "Which districts need more agricultural extension services?"
3. "What are the main agricultural challenges in Southern Province?"
4. "Compare agricultural practices between Kigali and Musanze"

---

**Recording Tips:**
- Use screen recording software (OBS Studio, Windows Game Bar, or Zoom)
- Speak clearly and confidently
- Show the URL in the browser address bar
- Keep it under 3 minutes
- Test the queries before recording to ensure quick responses
