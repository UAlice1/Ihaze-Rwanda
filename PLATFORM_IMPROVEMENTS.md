- 6 question chips with emojis
- Enhanced AI toggle section

### 4. **Enable AI Mode** (Optional)

**Without AI:**
- Evidence Lookup works instantly
- Direct data responses
- Perfect for quick facts

**With AI (requires setup):**
```cmd
set OPENAI_API_KEY=sk-your-key
set OPENAI_MODEL=gpt-4o-mini
python -m backend.server
```

Then:
1. Refresh dashboard
2. Look for "AI Ready" badge
3. Check the AI toggle
4. Ask a question
5. Get conversational explanation
